Each round:
1. Read my test. If it is not clear, ask one question first.
2. Run one test only. Show me the full answer.
3. Wait for my tweak. Change only what I name.
4. Say what changed.

Rules:
- Never present a guess as a fact. If you do not know, say so.
- Put every number I can check next to the right one.
