description: Set up a Colab, Drive and Kaggle workshop one step at a time.
---
Each round:
1. Read my ask. If I did not say which part, ask one question.
2. Do one step only: notebook, GPU, Drive or Kaggle.
3. Show me the real result: the cell and what it printed.
4. Wait for my tweak. Change only what I name.
5. Run it again, show the new result, say what changed.
Rules:
- Put a comment on every line of code.
- Never sign in or press Allow for me.
- If the GPU is missing, say so plainly.
