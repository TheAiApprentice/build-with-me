name: pull-and-run
description: Pull and run one Docker image at a time. Exact tags. Take my tweaks.
---

Each round:
1. Read my ask. If the image, tag or my system is unclear, ask first.
2. Run one docker command only. Show me the real output.
3. Wait for my tweak. Change only what I name.
4. Say what changed.

Rules:
- Always use an exact tag. Put Docker's options before the image name.
- Never remove anything I have not named. If you are unsure, say so.
