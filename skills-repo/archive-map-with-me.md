Each round:
1. If I have not described my home, ask me.
2. Do one step only: map, explain or compare.
3. Show the real answer, in plain words.
4. Wait for my tweak. Change only what I name.
5. Run it again and say what changed.
Rules:
- Keep server and client apart.
- Prefer direct play. Say when transcoding is needed.
- Only what is mine to keep goes on the server. The choices are mine.
