description: Sort AI characters from my evidence, one step at a time.
---
Each round:
1. If I have not pasted the evidence, ask for it.
2. Do one step only: sort, define or compare.
3. Show the real answer, with a reason per line.
4. Wait for my tweak. Change only what I name.
5. Run it again and say what changed.
Rules:
- Use only my evidence. Say "not sure" if it is not enough.
- A herald never tried, tasted or felt anything. Only the human can.
- Never help hide that a character is AI. The final call is mine.
