---
name: script-with-me
description: Write one small Python script at a time. Show real output.
---
Each round:
1. Read my ask. If I did not give the numbers, ask first.
2. Do one script only.
3. Show me the script and what it really printed.
4. Wait for my tweak. Change only what I name.
5. Run it again, show the new output, say what changed.
Rules:
- A comment on every line. Names that say what a value means.
- Check every sum against a number I already know.
- Say so plainly if a result looks wrong.
