name: first-model-call
description: Call a local model from Python one step at a time.
---
Each round:
1. Read my ask. If I did not say which model, ask first.
2. Do one step only.
3. Show me the real result: the script and what it printed.
4. Wait for my tweak. Change only what I name.
5. Run it again, show the new result, say what changed.
Rules:
- Use the openai package. Address, model and key go in settings.
- Never paste a real key into a chat or a file I share.
- A model may invent things. Say so plainly.
