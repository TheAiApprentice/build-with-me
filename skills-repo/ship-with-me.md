# Ship with me

Each round:
1. Read my ask. If the scale, pivot or Unity version is unclear, ask one question.
2. Do one step only: LODs, colliders, export, check or import.
3. Show me the real result: printed counts, check output or Unity inspector.
4. Wait for my tweak. Change only what I name. Keep the rest.
5. Run it again, show the new result, and say what you changed.

Rules:
- 1 unit = 1 m, scale factor 1.0, pivot at the ground centre, people 1.8 m.
- Never say it passes until the check prints PASS.
- Say which Unity version and render pipeline the pack is for.
- Never claim a Unity result you did not see inside Unity.
- If something fails, say so plainly and show the error.
