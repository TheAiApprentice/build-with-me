## What The AI Apprentice is

The AI Apprentice is a learning channel, guided by **Master Quill**, an old archivist of the Guild, and **Askling**, the lantern.
The idea is simple: AI is a tool you work *with*, not a magic button.

- **Real work, not demos.** Each video shows a real project built from start to finish: the first result the AI really gave,
  what was wrong with it, the tweak, and the fixed result. Nothing is faked or pre-made.
- **The honest side too.** Every part of a video says what the AI does well, where it is still weak, what it costs, where it
  runs, and the catch, so you can decide whether to use it or do that part by hand.
- **You keep the method.** The starter skill is the part you take home. It turns the way of working from the video into
  instructions your own AI follows.

## How a starter skill works

Each file is a short set of instructions for an AI assistant. They all follow the same rules:

1. **One step at a time.** The AI does one small step, shows you the real result, and stops.
2. **Real results only.** It shows real output from your own files or tools. It never pretends something ran.
3. **Your tweak decides the next step.** It changes only what you name and shows you before and after.
4. **It tells you what it can't know.** No invented facts, prices or details passed off as real.

## How to use one

**With Claude Code (or any tool that reads `SKILL.md` skills):**

1. Pick a file from the table below, for example `song-with-me.md`.
2. Make a folder with the same name in your skills folder, for example `.claude/skills/song-with-me/`.
3. Save the file in that folder as `SKILL.md`.
4. Start a new session and ask for the job. The AI loads the skill on its own.

**With any chat AI (ChatGPT, Claude, Gemini, a local model):**
open the file, copy all of it, paste it as the first message (or into the custom instructions), then tell it what you want to make.

## Good to know

- **Check the AI's work.** The skills make the AI show its real results so you can check them. They don't make it always right.
- **Your files stay yours.** The skills themselves don't send data anywhere. If you use a cloud AI (ChatGPT, Claude, Gemini), your chats go to that provider, so use a local model for anything private.
- **Paid tools are optional.** Where a video uses a paid tool, it also names a free one, and the skill works with either.
